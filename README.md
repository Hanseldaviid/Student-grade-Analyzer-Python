# Student Grade Analyzer (CLI)

A Python Command-Line Interface (CLI) application designed to manage student records and calculate classroom statistics. This project focuses on modular function design, parameter passing, dictionary state management, and robust input validation.

## 🚀 Features

- **Student Registration:** Captures student names and validates numerical grades within a defined range ($0.0 - 5.0$).
- **Roster Overview:** Displays all registered students alongside their respective grades.
- **Classroom Statistics:** Calculates the overall class average and dynamically identifies the top-performing student.
- **Input Validation:** Handles invalid inputs and menu choices smoothly using `try...except` blocks and loops.
- **Clean Architecture:** Built using modular helper functions and Python's `match/case` flow control.

## 🛠️ Built With

- **Python 3.10+**
